# Мастерская красоты

Готовый адаптивный сайт студии на Михневской, 7к2с1, Москва. Палитра, реальные фото интерьера, услуги и контакты основаны на трёх предоставленных фотографиях. Визуальная версия 2 дополнена редакционным AI-изображением; оно обозначено на сайте и не выдаётся за клиента или работу студии. Обоснование дизайна и источники трендов — в DESIGN.md. Статическая сборка работает без базы данных, API-ключей, внешних шрифтов и платных сервисов.

## Локальный запуск

Требуется Node.js 22.13+ и npm.

```sh
npm ci
npm run build
npm start
```

Открыть **http://127.0.0.1:3000**. Если зависимости и сборка уже на месте, достаточно `npm start`. Остановка в терминале — `Ctrl+C`.

Для разработки с автоматическим обновлением:

```sh
npm run dev
```

Адрес разработки: http://127.0.0.1:5173.

Другой порт: `PORT=8080 npm start`. Для сервера за HTTPS reverse proxy: `HOST=0.0.0.0 PORT=3000 npm start`. По умолчанию локальный сервер доступен только на этом компьютере.

## Публикация

Содержимое **out/** — готовый сайт. Его можно загрузить на обычный статический хостинг. Node.js на хостинге не нужен. Главная страница: `index.html`, страница конфиденциальности: `privacy/index.html`, страница ошибок: `404.html`.

1. Выполнить `npm ci && npm run build` или использовать приложенный архив готовой сборки.
2. Загрузить всё содержимое `out/` в корень сайта, включая `_next/`, `fonts/`, `images/`, `brand/`, файлы иконок и `404.html`.
3. Подключить свой домен и HTTPS в панели хостинга.
4. Настроить выдачу `404.html` с HTTP-статусом 404 для несуществующих адресов. Не включать SPA-перенаправление всех адресов на главную.

Файл `_headers` задаёт заголовки для статических платформ, которые поддерживают этот формат. GitHub Pages этот файл не применяет: HTTP-заголовки контролирует платформа. На Nginx или другом сервере их необходимо перенести в конфигурацию хостинга. В локальном сервере включены `nosniff`, защита от встраивания, Referrer-Policy и запрет ненужных разрешений.

Адрес GitHub Pages: https://lucem-afferens.github.io/masterskaya-krasoty/. Исходники — в ветке `main`, статическая сборка — в `gh-pages`, источник Pages — корень этой ветки.

`npm run build:pages` собирает сайт с префиксом `/masterskaya-krasoty`, сохраняет `.nojekyll` и служебный `.base-path` для локального сервера. После такой сборки `npm start` автоматически обслуживает этот префикс и перенаправляет на него корневой адрес. Обычная команда `npm run build` сохраняет работу в корне домена.

`npm run deploy:pages` требует чистого рабочего дерева, настроенного `origin` и доступа Git на запись. Скрипт собирает сайт, записывает SHA исходного коммита в сообщение коммита сборки и отправляет ветку `gh-pages` без force-push. Первичная настройка Pages в репозитории выполняется отдельно; после неё каждый push сборки запускает размещение. Обновления только в `main` сайт автоматически не публикуют.

Пути изображений, иконок и обычных ссылок проходят через `lib/paths.ts`; Next.js получает тот же `basePath` во время сборки. Шрифты включаются в CSS как локальные зависимости, поэтому пути также учитывают префикс. Основа настройки: [Next.js basePath](https://nextjs.org/docs/app/api-reference/config/next-config-js/basePath) и [источник GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Что работает

- Адаптивная вёрстка, мобильное меню в модальной панели с пояснениями к разделам и нижняя кнопка записи.
- Футер с приглашением на визит, навигацией, телефонами мастеров, адресом и ссылкой на карту; на телефоне — сетка из двух колонок.
- Два направления услуг, раскрывающиеся описания и выбор конкретной услуги.
- Запись напрямую по телефону; Telegram подключён только для направления эстетики тела, согласно QR-коду на исходном фото.
- Окно записи с переключением направления, правильными контактами, копированием номера, клавиатурной навигацией и закрытием по Escape.
- Галерея с увеличением, кнопками и стрелками клавиатуры. Два детальных кадра — фрагменты реальной фотографии интерьера, а не отдельные съёмки.
- Частые вопросы, адрес и интерактивный виджет Яндекс Карт с меткой здания на Михневской, 7к2с1. Под картой есть отдельная ссылка на адрес. Виджет загружается от Яндекса, требует доступа к интернету и не требует API-ключа в проекте.
- SEO-метаданные, русская локаль, schema.org BeautySalon, favicon, robots.txt.
- Страницы конфиденциальности и 404, обработка ошибок загрузки, оптимизированные WebP-фото, локальные WOFF2-шрифты с OFL-лицензиями.

Сайт не принимает заявки на сервер и не показывает фиктивные свободные слоты. Время и стоимость подтверждает мастер при разговоре или переписке. У пользователя не запрашиваются персональные данные. Цены, отзывы, регалии и гарантии результата не выдуманы.

## Где менять информацию

- `lib/studio.ts` — контакты, адрес, услуги, расписания, FAQ.
- `app/page.tsx` — блоки главной страницы и интерактивность.
- `app/globals.css` — цвета, шрифты, сетки и адаптивность.
- `app/layout.tsx` — SEO и структурированные данные.
- `app/privacy/page.tsx` — информация о конфиденциальности.
- `public/images/` — оптимизированные фотографии.
- `public/brand/` — выбранный логотип: горизонтальная версия для шапки и вертикальная для подвала.
- `public/favicon*` и `public/apple-touch-icon.png` — иконки на основе монограммы «МК».
- `scripts/serve.mjs` — локальный сервер готовой сборки.

После изменения контента заново выполнить `npm run build`. Если изменяются контакты, сверить их также в SEO-разметке, странице конфиденциальности, FAQ и smoke-проверках.
